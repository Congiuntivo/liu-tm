# Identifying Large Language Models from Generated Text

A case study in Italian counseling dialogues. Course project for
**TDDE16 Text Mining** at Linköping University, Erasmus+ semester
(September 2025 - January 2026).

**Question.** Can we identify which LLM generated a conversation
using only the text, under identical prompts and task protocols?

**Approach.** TF-IDF *n*-gram representations combined with
unsupervised k-means clustering and a linear SVM classifier, with
LIME interpretability. Applied to Brief Action Planning (BAP)
counseling dialogues generated by four LLMs.

**Result.** Near-perfect separation between the four models.
Interpretability analysis shows that lexical choices, phrasal
patterns and even personal names contribute to each model's
fingerprint. Simple formatting features alone reach 90 % accuracy,
indicating that surface-level cues also reflect model-specific
tendencies.

## Stack

Python (`uv`), scikit-learn, LIME, Jupyter, LaTeX (ACL template) for
the report.
